# Changelog

## 1.0.4 - 2026-10-07

Windows release published on <https://deviops.app/tools/devi-registry/>. This repository holds the community scaffolding and brand assets for the open-source home; application source under `src/` and data under `data/` follow as they are published.

- Offline Windows app for looking up application and artifact metadata by name, Android package, or Apple bundle ID.
- Sourced JSON and YAML snapshots with claim status (verified, reported, or disputed).
- Optional update check, off by default.
- Public UI guidance: no third-party logos or colored letter-tile avatars in this tree.

## Repository

- Added Apache-2.0 license, NOTICE, contributing guides, security policy, and issue templates aligned with DEVI Validate.
