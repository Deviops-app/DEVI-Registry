# Contributing to DEVI Registry

Thank you for your interest in DEVI Registry. This repository holds the DEVI community files and brand assets for Registry, and is the home for the application source and data snapshots as they are published.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Reporting bugs and asking for features

- **Bugs:** open an issue with the bug report form. Include the DEVI Registry version (About window), the operating system, the steps to reproduce, and relevant lines from `%LocalAppData%\DEVI\Registry\logs` when present.
- **Features:** open an issue with the feature request form. For a new or corrected record, name the public source and the date you read it.
- **Security issues:** do not open a public issue. Follow [SECURITY.md](SECURITY.md).

Never attach real case material, device images, or personal data to an issue or pull request.

## UI and branding

Do not add third-party product logos or colored letter-tile avatars as app stand-ins. Use plain text labels and the shared DEVI brand assets under `assets/brand`.

## Pull requests

1. One logical change per pull request.
2. Fill in the pull request template.
3. Every behavior change adds a line to `CHANGELOG.md` under an "Unreleased" heading.
4. A DEVI maintainer reviews and merges every change.

The repository never contains credentials, signing keys, internal infrastructure details, personal information, or case data.
